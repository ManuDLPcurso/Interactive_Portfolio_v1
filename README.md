# Interactive Portfolio

## 📖 Descripción

Interactive Portfolio es un portfolio personal desarrollado con React que simula una terminal interactiva.

La aplicación permite consultar información mediante comandos, explorar las tecnologías utilizadas y visualizar proyectos con demostraciones integradas.

---

# 🚀 Uso

Al cargar la aplicación aparecerá una terminal lista para recibir comandos.

Escribe un comando y pulsa **Enter**.

Ejemplo:

```bash
help
```

---

# 📋 Comandos disponibles

| Comando    | Descripción                                          |
| ---------- | ---------------------------------------------------- |
| `help`     | Muestra todos los comandos disponibles.              |
| `about`    | Información personal y profesional.                  |
| `skills`   | Tecnologías organizadas por categorías desplegables. |
| `projects` | Muestra la lista de proyectos.                       |
| `contact`  | Información de contacto.                             |
| `clear`    | Limpia la terminal.                                  |

---

# 💼 Proyectos

Cada proyecto muestra:

* Descripción.
* Tecnologías utilizadas.
* Funcionalidades principales.

Además, cada uno dispone de un desplegable **DEMO**, que carga una demostración interactiva mediante un **iframe**, permitiendo probar el proyecto sin abandonar el portfolio.

Debajo de cada proyecto también se incluyen enlaces directos al:

* Repositorio de GitHub.
* Demo en vivo (cuando está disponible).

---

# 🛠 Habilidades

Las tecnologías se encuentran organizadas por categorías desplegables para facilitar su consulta:

* Frontend
* Backend
* Databases
* Herramientas
* Otros

---

# 📬 Contacto

El comando:

```bash
contact
```

muestra diferentes formas de contacto.

El correo electrónico utiliza un enlace `mailto:`, que abrirá automáticamente la aplicación de correo predeterminada del usuario para redactar un nuevo mensaje.

También encontrarás enlaces directos a:

* GitHub
* LinkedIn
* Currículum Vitae

---

# 💡 Recomendación

Si es la primera vez que utilizas la aplicación, comienza escribiendo:

```bash
help
```

para descubrir todos los comandos disponibles.
